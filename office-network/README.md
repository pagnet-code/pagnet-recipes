# office-network

A small-office starter: sales and support agent templates, plus references
to the services an office network usually wants — a CRM service (search the
public directory or connect your own) and the document-service from this
repo.

    pagnet recipe apply office-network

Then add the CRM and document services to the network. Suggested
subscriptions: `ticket.*` for the support agent, `deal.*` for sales.

Interesting property: an office network is mostly agents talking to
services — no special "business" concept exists in the protocol.
